# Security policy

Report vulnerabilities privately to [saul@saugar.dev](mailto:saul@saugar.dev).
Include the affected commit, impact and reproduction steps. Do not open a public
issue or send live credentials or other people's data.

Fixes target the latest code on `main`. This project is experimental and assumes
a trusted host operator and maintainer-approved repository code. Read the
[security boundary](docs/README.md#security-boundary) before enabling live tasks.
