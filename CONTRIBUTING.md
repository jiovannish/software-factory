# Contributing

Bug reports and focused pull requests are welcome. Include reproduction steps
and relevant test output, without credentials or private VM data.

Run the [local checks](docs/README.md#local-development) before submitting a change.
Keep task orchestration here; runtime, control-plane policy and template recipes
belong in their respective Jio repositories.

Follow our [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately
using [SECURITY.md](SECURITY.md).
